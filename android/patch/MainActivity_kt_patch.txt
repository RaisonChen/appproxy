==========================================================
可选补丁：让「安装 CA 证书」按钮真正弹出系统安装界面
==========================================================
⚠️ 如果你不想碰 Kotlin，跳过此文件即可。
   Dart 端会退化为「提示用户手动去系统设置安装」。

需要修改的文件：
  android/app/src/main/kotlin/cn/ys1231/appproxy/MainActivity.kt

在 configureFlutterEngine() 里增加一个新的 MethodCallHandler 分支，
处理 "installCa" 调用。完整补丁如下：

----------------------------------------------------------
1) 在文件顶部 import 区域加上（如已有则跳过）：
----------------------------------------------------------
import android.content.Intent
import android.net.Uri
import java.io.File

----------------------------------------------------------
2) 在 configureFlutterEngine() 里，已有的 MethodChannel 处理
   代码（处理 startVpn / stopVpn 的那个）旁边，加一个
   "installCa" 分支。伪代码示意：

   FLUTTER_VPN_CHANNEL = MethodChannel(flutterEngine.dartExecutor, "cn.ys1231/appproxy/vpn")
   FLUTTER_VPN_CHANNEL!!.setMethodCallHandler { call, result ->
       when (call.method) {
           "startVpn" -> { /* 原版已有，不动 */ }
           "stopVpn"  -> { /* 原版已有，不动 */ }
           "installCa" -> {
               val path = call.argument<String>("path")
               if (path == null) {
                   result.error("NO_PATH", "path is null", null)
               } else {
                   try {
                       val file = File(path)
                       val uri = Uri.fromFile(file)
                       val intent = Intent(Intent.ACTION_VIEW)
                       intent.setDataAndType(uri, "application/x-x509-ca-cert")
                       intent.flags = Intent.FLAG_ACTIVITY_NEW_TASK
                       intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
                       startActivity(intent)
                       result.success(true)
                   } catch (e: Exception) {
                       result.error("INSTALL_FAILED", e.message, null)
                   }
               }
           }
           else -> result.notImplemented()
       }
   }

----------------------------------------------------------
3) 不需要新增任何权限（安装用户证书不需要特殊权限）。
----------------------------------------------------------

打上这个补丁后，Dart 端 platform.invokeMethod('installCa', ...)
就能真正弹出系统「安装证书」界面，用户确认后按钮永久隐藏。
